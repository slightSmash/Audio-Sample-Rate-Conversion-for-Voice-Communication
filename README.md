# Audio-Sample-Rate-Conversion-for-Voice-Communication
MATLAB-based DSP mini-project on audio sample-rate conversion for voice communication, comparing linear interpolation, Kaiser-window FIR filters, equiripple FIR filters, Butterworth IIR filters, and MATLAB's `resample` function using SNR, in-band SNR, log-spectral distortion (LSD), and execution time.
